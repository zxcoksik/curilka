CATALOG — VS CODE

Структура:
catalog/
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   ├── products.js
│   │   └── script.js
│   └── images/
│       └── фотографии товаров
└── README.txt

Запуск:
1. Распакуйте проект.
2. В VS Code выберите File → Open Folder.
3. Откройте папку catalog.
4. Запустите index.html через Live Server.

Одна адаптивная версия используется и на ПК, и на телефоне.
Фотографии сопоставлены с товарами по photo ID из таблицы.
